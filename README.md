# rag-assistant-agent-v2

Assistente em linguagem natural sobre a base interna da Cristalux (vendas, compradores, vendedores, estoque e decisões), com RAG para textos e consulta SQL em PostgreSQL para dados tabulares.

Projeto em desenvolvimento orientado por especificação. As especificações estão em [specs/](specs/README.md). Este README será completado ao final do projeto.
